🕵️ Kiểm tra dấu hiệu chỉnh sửa / lệch GPS

📷 Tải ảnh lên kiểm tra (chưa cần biết thuộc hợp đồng nào)

Dùng khi cần kiểm tra nhanh 1 ảnh hiện trường trước khi quyết định gán vào hồ sơ hợp đồng nào. Tự đọc tọa độ GPS theo 2 cách: EXIF ảnh (nếu máy có bật định vị lúc chụp), hoặc tem tọa độ in sẵn trên ảnh kiểu app "GPS Map Camera" (đọc bằng Gemini — cần đã cấu hình API key ở Thiết lập).

⚠️ Nếu hộp thoại chọn file bị treo/đơ (thường do OneDrive/Explorer đồng bộ chậm trên máy), dùng cách 2 bên dưới thay thế.

🗂️ Ảnh đang chờ xử lý (chưa gán / chờ duyệt)

Bấm "Tải danh sách" để xem.

🔎 Đối chiếu OCR file gốc (DinhKemGiayTo) với dữ liệu đã nhập

OCR file PDF/ảnh minh chứng bằng Gemini, so khớp số CCCD/số giấy tờ với dữ liệu trong Sheet. Cần đã cấu hình API key Gemini ở trang Thiết lập → 🤖 Chatbot (dùng chung, không cần nhập lại). Chạy khá chậm — nên chạy vào cuối ngày hoặc để trigger tự động.

💡 Muốn XEM kết quả ngay trên trang này (cột "Kết quả" bên dưới) → dùng nút "▶️" bên phải. Nút "⚙️" bên trái chỉ ghi vào Sheet BaoCao_DoiChieuOCR để lưu trữ/đối chiếu số lượng lớn định kỳ — bảng dưới đây sẽ KHÔNG tự cập nhật, phải mở Sheet đó ra xem.
